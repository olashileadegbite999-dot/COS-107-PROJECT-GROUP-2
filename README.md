# ÉLÉGANCE NOIR — Luxury Perfume Landing Page

A luxury perfume product landing page designed and developed by **Cyber Security Group 2** as a creative web development project.

---

## Pages & Sections

- **Hero** — Brand introduction with a call-to-action button
- **Products** — 6 featured perfume cards with descriptions, notes, ratings, and prices
- **Categories** — 6 perfumes organized by collection (Men, Women, Unisex)
- **About** — Project overview and team information
- **Footer** — Group credit

---

## Files

| File | Purpose |
|------|---------|
| `mainperfume.html` | Main HTML structure |
| `perfume.css` | Styling and layout |
| `perfume.js` | Interactivity (scroll, particles, cart alerts) |

---

## Features

- Sticky navigation with smooth scroll
- Floating particle animation on the hero section
- Responsive product grid
- Add to Collection button with alert feedback
- Fade-in animation on cards using Intersection Observer

---

## How to Run

1. Clone or download the project folder
2. Make sure the `Images/` folder contains all product images
3. Open `mainperfume.html` in any modern browser
